## Design

An explicit source Review video action can include the first up to 30 source seconds of audio when the local operator enables OPENREEL_SOURCE_AUDIO and a transcription provider is configured. Existing local-upload behavior and optional CLI frame-description behavior remain unchanged. Native public-player capture uses the existing 45s/50MiB bounds and owned-browser cleanup. Audio is sampled before frame seeks, at normal playback rate, through a permitted media-element stream; no microphone, system audio, direct media fetching or video file is used. No retries after unavailable/protected audio. If the ordinary API cannot provide an accessible non-silent track within the bounds, return an explicit unavailable reason and retain valid visual-only review. Any source/identity/access/geometry barrier still invalidates the capture.

A self-contained browser helper collects mono PCM16 16kHz for at most 30s / 1MiB canonical WAV, checks actual source progress against captured duration, and cleans up processor/streams/context on every exit. Observe source start/end playheads and waveform duration separately; do not pretend PCM timing verifies exact word positions. No altered playback speed. Keep output silent using a zero-gain sink. No autoplay-policy override; a suspended context is unavailable. Before/after audio sampling, validate source access and identity through the existing checks.

Node validates WAV, source URL/creator, duration, receipt and SHA-256 before one real transcription request. Use the existing transcriber with parent cancellation propagated into its fixed 45s timeout. Transcription remains machine-generated unverified text. The vision model receives sampled images plus transcript text, not raw audio; do not claim acoustic analysis, voice identity, music, delivery or continuous motion. It may use supplied words to critique opening copy. Capture raw audio is discarded after transcription and never cached/exported or written into corpus. At most two frame/transcript contexts remain in memory for ten minutes, unchanged. Explicit follow-ups reuse the same transcript without recapture or retranscription.

Attach separate validated audio-capture provenance to source videoAnalysis: actual canonical source/creator, observed capture time, sampled source interval, WAV duration/hash, and transcription status. Keep existing frame provenance. Saved workspace retains only bounded metadata/text, no WAV/frame data or session token. Reload preserves citations/transcript scope; ephemeral context still requires explicit Review video to recreate. Existing saved visual-only answers must remain valid. UI states partial opening-speech coverage and machine-transcript limits plainly, without implying the entire source was heard. Full source/raw-acoustic coverage remains an open requirement.
